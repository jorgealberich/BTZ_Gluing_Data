# BTZ gluing data

This repository contains the parameter sets used to construct the
representative scalar-field profiles presented in [paper title/arXiv].

The profiles are defined by

Xi(U0,V) = P(V) f1(V) exp(i V f2(V)),

with f1 and f2 parametrised as described in the paper.

## Files

- `profiles.wl`: Mathematica definitions needed to reconstruct the profiles.
- `parameters_r02_m4.wl`: parameters for r+/ell = 0.2, m = 4.
- `parameters_r1_m5.wl`: parameters for r+/ell = 1, m = 5.
- `parameters_r10_m400.wl`: parameters for r+/ell = 10, m = 400.
